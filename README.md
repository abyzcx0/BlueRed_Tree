​BR-Tree: The Blue-Red Binary Search Tree 🌳🔵🔴
​BR-Tree es una variante del árbol Rojo-Negro (Red-Black Tree) que implementa una política de corrección mas estricta. 
A diferencia del estándar industrial, el BR-Tree considera tambien dos hermanos ambos rojos como violacion rojorojo. 
Esta especificacion fuerza una estructura más similar a un Árbol 2-3.
